Modernize an Angular 8 App.

We Were Quoted 3 Months to Modernize an Angular 8 App. We Shipped the Core in a Weekend.

Rivendellai Inc. — June 2026

Every software company has one: the application that runs the business but that everyone is afraid to touch. Ours was the ProSale Company Portal — the operational heart of our estate-sale platform. Sales setup, inventory cataloging, client management, point of sale, payments, reporting. All of it running on Angular 8, Node 12, and TypeScript 3.5 — a stack that was already legacy when the 2020s started.

The honest assessment, from people who know what they’re talking about: about three months of effort to bring it to a modern stack. Thirteen major Angular versions behind. Roughly 80 runtime dependencies, many of them abandoned years ago — the smart-table library, the OIDC client, the file uploader, the perfect-scrollbar, the video player nobody remembered adding. You can’t upgrade through thirteen majors when half your dependency tree has no compatible version on the other side. The only honest path was a rewrite.

So we rewrote it. The core of the system — 18 commits, nearly 20,000 lines of production code, 50 components, 19 services — landed in one weekend.

What actually shipped

This wasn’t a skeleton or a proof of concept. Over two days, the new portal went from an authentication shell to feature-complete for the core business:

  • Company management — profile, addresses, contacts, payment options, commission rules, discount groups, quick-add catalogs, and the full Square merchant onboarding: OAuth connect, location selection, card terminal pairing with device codes, POS stand registration
  • The complete sales lifecycle — eleven filtered sales views, a guided create-sale wizard (client → details → schedule → confirmation), and an eleven-tab sale workspace covering scheduling with per-day discount periods, expenses, commissions, documents, communications, and merge/grouping
  • Inventory — cataloging with multi-photo upload, per-day discount pricing, stock validation, and SKU generation
  • A full point of sale — ticket management, a register with barcode scanning, quick-add grids and out-the-door pricing, and a checkout that takes real payments through Square: card terminals, the in-browser Square Web SDK, the Square POS tablet app, cash with change calculation, checks, and partial payments — with PDF and email receipts
  • Customers and clients — searchable directories with full profiles
  • Reporting — rebuilt on our new document-generation pipeline, where reports assemble live data from microservices instead of a warehouse
  • Production packaging — a Docker/ECR/Kubernetes pipeline matching our existing deployment flow, image built and verified

And the result is dramatically lighter. The legacy portal is 77,861 lines of application code across 776 files (121 components, 46 services). The new one does the core job in 15,037 lines across 156 files (50 components, 19 services) — roughly 80% less code. That’s what happens when you delete the smart-table data-source classes, the subscription-manager boilerplate, the wrapper components that existed only to feed abandoned UI libraries, and the dead code that could never execute. The dependency list went from ~80 packages to 11. The initial bundle a browser downloads is now about 190 KB. Every commit built clean.

How a weekend replaced a quarter

Three things made this possible, and only one of them is the obvious one.

1. AI pair programming — used the way it should be. We ran the migration as a continuous working session with Claude (Anthropic’s Claude Code), and the workflow mattered more than the tool: the AI read the legacy component, the service it called, and the actual API contract before writing a line. Every screen was ported against the real request shapes the backend expects — the same filter parameters, the same DTO field casing, the same round-trip mappings. When the new sales list showed every sale instead of one type, the fix came from re-reading the legacy data source and discovering the backend wanted filterType=Residence, not a special-type flag. That’s contract archaeology, done at machine speed.

2. A proven reference implementation. We had already modernized our admin portal. Its patterns — standalone components, signal-based state, a tolerant DTO-mapping layer, plain Bootstrap tables instead of grid libraries — became the template. The new portal didn’t invent an architecture on the fly; it applied one that was already battle-tested in production. If you’re planning a legacy rewrite, this is the multiplier nobody prices in: modernize one system carefully, then let it set the rules for the rest.

3. Ruthless scoping — and the dead code told us where to cut. Reading every legacy file before porting it paid for itself in what we didn’t migrate. A category-editing UI that had been hard-locked behind a categoriesLocked = true flag — hundreds of lines that could never execute. Client routes that read a URL parameter their own router never supplied. A price editor whose change handler was empty. A reporting warehouse that had already been decommissioned server-side. The three-month estimate implicitly included rewriting all of that. The weekend didn’t.

Honest footnotes

A few peripheral areas are still queued — label printing, email campaign templates, CSV imports, POS returns — so the line-count comparison flatters the new portal a little; even porting all of it, we expect to land at well under a quarter of the legacy size. And a thorough end-to-end test pass against the live backend comes before the production cutover. Nobody should claim AI removes the need for verification; it removes the typing, the searching, and the forgetting. The judgment calls — what to port, what to kill, what the business actually uses — were human ones, made faster because the full picture was always on the table.

The takeaway

The three-month estimate wasn’t wrong — it was right for the old way of working. Read a file, understand it, rewrite it, test it, repeat several hundred times. What changed is that the read-understand-rewrite loop now runs at a different clock speed, while the architecture, the priorities, and the taste stay human.

If you’re staring down your own “untouchable” legacy system — the one quoted in quarters, not weeks — the math has changed. We’d be glad to show you ours.
