Modernizing Prosale Without Breaking the Business

At RivendellAI, we’ve been quietly doing the unglamorous work that actually matters: modernizing Prosale’s core web platform without disrupting day-to-day estate sale operations.

One of our biggest recent efforts was upgrading the Prosale admin and company portals from Angular 8 and Node 12 to the latest versions—using a pure lift-and-shift methodology.

No redesign. No feature creep. No “rewrite it all and hope.”

Why This Matters for Prosale Users

Prosale runs live sales, real payments, real inventory, and real reporting. That means stability comes first.

So instead of changing behavior, we focused on preserving functionality while upgrading the foundation.

Every screen, workflow, and permission path in the new system was compared directly against the legacy application to ensure it behaved the same—just faster, cleaner, and more maintainable.

How We Approached the Upgrade

We started with the essentials:

  • Authentication and authorization wired into our Duende IdentityServer backend

  • A modern, consistent application layout

  • Secure navigation and role-based access fully verified

From there, we migrated individual components one by one, validating each step before moving forward.

Moving to Modern Angular (The Right Way)

The legacy system was built using Angular’s older module-based architecture. The new Prosale web platform is built using standalone Angular components.

That shift alone:

  • Reduced complexity

  • Eliminated unnecessary abstractions

  • Made the system easier to support and extend going forward

We also made a conscious decision not to carry forward obsolete third-party libraries. If something wasn’t actively used or didn’t make sense in modern Angular, it stayed behind.

AI-assisted refactoring helped us safely convert existing components, allowing our engineers to focus on correctness and architecture instead of repetitive mechanical work.

The Results Speak for Themselves

This modernization produced some meaningful, measurable wins:

  • Node modules reduced from 725 MB to 225 MB

  • Source code cleaned up from 550 files / 104 folders to just 107 files / 24 folders

That wasn’t just refactoring—it was removing years of unused baggage while keeping Prosale’s behavior intact.

What This Means Going Forward

For Prosale customers and partners, this means:

  • A more reliable platform

  • Faster builds and deployments

  • A codebase designed for future features—not fighting them

For RivendellAI, it means Prosale now sits on a modern, sustainable frontend foundation that can evolve alongside the business.

Sometimes the most important upgrades are the ones users never notice—but benefit from every day.
